# Architecture Decision Records (repo-wide)

Decisions that affect the whole repository: its layout, shared tooling and
conventions between packages. Decisions that belong to one package live in
that package's own `docs/adr/` (for the frontend template,
`packages/templates/web/docs/adr/`).

**Format:** one file per decision, numbered sequentially, using the sections
Context, Decision, Alternatives Considered and Consequences. ADRs are never
edited to reflect a reversed decision: write a new ADR that supersedes the old
one and note the supersession in both.
